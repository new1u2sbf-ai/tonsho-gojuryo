# 屯所の五十両（百物語の番人 前日譚）

慶応二年、初雪の朝。浪士隊「朱雀組」の屯所から、軍資金五十両が消えた。
監察方の見習いとして手がかりを集め、盗人を挙げる、約15分の無料推理ゲームです。スマホのブラウザで遊べます。
